# 常见问题

## 最重要

### 为什么这里的数字和 App 不一样？

左上角写着「示例数据」时，显示的是编出来的演示数字。关掉后双击「启动桌面小工具」（Windows 是 .bat，Mac 是 .command）看你自己的数据。如果是真实数据还对不上，多半是还没同步，点刷新。

## 连接和数据

### 第一次怎么连上我的 WHOOP？

需要先在 developer.whoop.com 建一个自己的 App（回调地址填 http://localhost:3000/callback），把 Client ID 和 Client Secret 粘贴到「⚙ 设置」里保存，再点「连接 WHOOP」。详见 README。

### 我的数据存在哪里？会上传吗？

只存在你电脑上的 data 文件夹，不会上传。只有你自己打开 AI 功能并点了「AI 帮我写」，才会把数字摘要发给你选的 AI。

### 提示「还没有数据」？

新设备至少要戴着睡一晚，WHOOP 才会算出第一份恢复度。

## 功能

### 为什么没有步数 / 压力监测？

WHOOP 官方接口不提供，只能在 App 里看。

### 心率区间时间为什么比 App 首页少？

这里和 App 一样，只统计你记录下来的运动。

### 今日建议是谁给的？

本工具按你的数据和固定规则生成，不是 WHOOP 官方建议，也不构成医疗建议。

## 窗口

### 窗口跑到屏幕外了？

删除项目文件夹里 data 文件夹中的 widget.json 后重新打开，会回到屏幕右上角。

### 隐藏以后找不到了？

Windows 按 Ctrl+Alt+W，Mac 按 Control+Option+W。

### 怎么重新看新手引导？

点 💡 帮助，第一页有「在页面上再带我走一遍」。

### Mac 上双击打不开，提示「无法验证开发者」？

第一次请在「启动桌面小工具.command」上点右键 →「打开」→ 再点「打开」。还是被拦的话，打开「系统设置 → 隐私与安全性」，拉到下面点「仍要打开」。Mac 版还在试用，详见 docs/试用步骤.md。

### Mac 上关掉终端窗口，小工具也没了？

是的。Mac 版是在终端窗口里运行的，小工具开着的时候不要关那个窗口；想退出就直接关小工具。
