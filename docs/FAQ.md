# 常见问题

## 最重要

### 为什么这里的数字和 App 不一样？

左上角写着「示例数据」时，显示的是编出来的演示数字。关掉示例预览，正常打开 Bridgepulse（下载版双击 Bridgepulse.exe 或 Bridgepulse.app；用源码运行的双击「启动桌面小工具」）看你自己的数据。如果是真实数据还对不上，多半是还没同步，点刷新。

## 连接和数据

### 第一次怎么连上我的 WHOOP？

需要先在 developer.whoop.com 建一个自己的 App（回调地址填 http://localhost:3000/callback），把 Client ID 和 Client Secret 粘贴到「⚙ 设置」里保存，再点「连接 WHOOP」。详见 README。

### 我的数据存在哪里？会上传吗？

只存在你自己的电脑上（具体位置见下一条），不会上传。只有你自己打开 AI 功能并点了「AI 帮我写」，才会把数字摘要发给你选的 AI。

### 打包版的数据存在哪里？

下载压缩包解压使用的（打包版），设置（.env）和数据（data 文件夹）不放在解压出来的文件夹里，而是放在系统给每个应用的文件夹：

- Windows：`%APPDATA%\Bridgepulse`（在文件资源管理器地址栏粘贴这一串回车就能打开）
- Mac：`~/Library/Application Support/Bridgepulse`（在访达里按 Shift+Command+G 粘贴）

所以换新版本时直接用新的压缩包替换旧文件夹就行，设置和数据都还在。用源码运行（npm install）的，还是在项目文件夹里的 .env 和 data。「⚙ 设置」框最下面会显示你这台电脑上实际的位置。

### 提示「还没有数据」？

新设备至少要戴着睡一晚，WHOOP 才会算出第一份恢复度。

## 功能

### 为什么没有步数 / 压力监测？

WHOOP 官方接口不提供，只能在 App 里看。

### 怎么跳到某一天？

点顶部「‹ 今天 ›」中间的日期，会打开恢复日历：每天的数字按恢复度上色（红 <34%、黄 34–66%、绿 >66%），点哪天就跳到哪天；灰色的日子没有数据。网页大看板点「今日解读」后面的日期也一样。

### 心率区间时间为什么比 App 首页少？

这里和 App 一样，只统计你记录下来的运动。

### 今日建议是谁给的？

本工具按你的数据和固定规则生成，不是 WHOOP 官方建议，也不构成医疗建议。

## 窗口

### 窗口跑到屏幕外了？

关掉小工具，删除 data 文件夹（位置见「打包版的数据存在哪里？」）里的 widget.json 后重新打开，会回到屏幕右上角。

### 隐藏以后找不到了？

Windows 按 Ctrl+Alt+W，Mac 按 Control+Option+W。

### 怎么重新看新手引导？

点 💡 帮助，第一页有「在页面上再带我走一遍」。

### Windows 提示「Windows 已保护你的电脑」？

这是因为 Bridgepulse 没有购买代码签名证书，第一次打开时 Windows 会提醒。点「更多信息」→「仍要运行」就行，以后不会再问。

### Mac 上双击打不开，提示「无法验证开发者」？

第一次请在 Bridgepulse.app 上点右键 →「打开」→ 再点「打开」。还是被拦的话，打开「系统设置 → 隐私与安全性」，拉到下面点「仍要打开」。Mac 版还在试用，详见 docs/试用步骤.md。

### Mac 上关掉终端窗口，小工具也没了？

只有用源码运行（双击「启动桌面小工具.command」）时才这样：小工具是在终端窗口里运行的，开着的时候不要关那个窗口。下载版 Bridgepulse.app 没有终端窗口。
