# Bridgepulse 脉桥 试用步骤

谢谢你帮忙试用。Bridgepulse 把你的 WHOOP 数据翻成中文，放在电脑桌面上。它是非官方工具，只读取数据，所有东西只存在你自己的电脑上。

先选你的电脑：[Windows](#windows) · [Mac（试用）](#mac试用)。

---

## Windows

1. **装 Node.js**：打开 [nodejs.org](https://nodejs.org)，下载 **LTS** 版本，一路「下一步」装好。
2. **下载 Bridgepulse**：打开 [github.com/HeathTeng/Bridgepulse](https://github.com/HeathTeng/Bridgepulse)，点绿色的 **Code → Download ZIP**，下载后右键 →「全部解压缩」，放到一个好找的地方（例如桌面）。
3. **第一次安装组件**：在解压出来的文件夹空白处按住 Shift 点右键 →「在此处打开 PowerShell 窗口」，输入 `npm install` 回车，等它装完（约 100MB，只需一次）。
4. **先看看效果（可选）**：双击 **示例数据预览.bat**，看到的都是编出来的数字，看完关掉。
5. **申请 WHOOP 开发者 ID**：按下面「申请 WHOOP 开发者 ID」一节做，拿到 Client ID 和 Client Secret。
6. **启动**：双击 **启动桌面小工具.bat**。
7. **粘贴密钥**：第一次打开会直接出现设置框（以后点顶栏的「⚙ 设置」），把 Client ID 和 Client Secret 粘贴进去，点「保存」。
8. **连接 WHOOP**：点「连接 WHOOP」，在浏览器里登录 WHOOP 并同意授权，回到小工具就能看到你的数据。

## Mac（试用）

Mac 版还没在真机上完整测过，你可能是第一批用的人，遇到问题请按最后一节告诉我。

1. **装 Node.js**：打开 [nodejs.org](https://nodejs.org)，下载 **LTS** 版本的 macOS 安装包（.pkg），双击装好。
2. **下载 Bridgepulse**：打开 [github.com/HeathTeng/Bridgepulse](https://github.com/HeathTeng/Bridgepulse)，点绿色的 **Code → Download ZIP**，在「下载」里双击 zip 解压，把文件夹拖到一个好找的地方（例如「文稿」）。
3. **第一次打开**：在文件夹里找到 **启动桌面小工具.command**，**右键 →「打开」→ 再点「打开」**（直接双击会被系统拦下）。如果还是打不开，去「系统设置 → 隐私与安全性」，拉到下面点「仍要打开」。
4. **等它装好**：会弹出一个「终端」窗口，第一次会显示「第一次使用，正在安装（约 100MB，只需一次）」，等它装完自动打开小工具。**小工具开着的时候不要关这个终端窗口**，关了小工具也会退出。
5. **申请 WHOOP 开发者 ID**：按下面「申请 WHOOP 开发者 ID」一节做，拿到 Client ID 和 Client Secret。
6. **粘贴密钥**：第一次打开会直接出现设置框（以后点顶栏的「⚙ 设置」），把 Client ID 和 Client Secret 粘贴进去，点「保存」。
7. **连接 WHOOP**：点「连接 WHOOP」，在浏览器里登录 WHOOP 并同意授权，回到小工具就能看到你的数据。
8. **以后每次**：双击 **启动桌面小工具.command** 就行；只想看示例效果就双击 **示例数据预览.command**。

## 申请 WHOOP 开发者 ID

每个人都要用自己的 WHOOP 账号申请一份，免费。

1. 打开 [developer.whoop.com](https://developer.whoop.com)，点进开发者后台（Developer Dashboard），用你的 WHOOP 账号登录。第一次进去可能要先建一个团队（Team），名字随便填。
2. 点 **Create App**（新建应用），按下面填：

   | 格子 | 填什么 |
   |---|---|
   | App name（应用名） | 随便，例如 `My Bridgepulse` |
   | Contacts（联系邮箱） | 你自己的邮箱（只给 WHOOP 看，不会给 Bridgepulse） |
   | Privacy policy（隐私政策网址，如果要求填） | `https://github.com/HeathTeng/Bridgepulse` |
   | Redirect URL（回调地址） | `http://localhost:3000/callback`（一个字都不能错，不要加空格） |
   | Scopes（权限） | 勾选所有 **read** 开头的：`read:recovery`、`read:cycles`、`read:sleep`、`read:workout`、`read:profile`、`read:body_measurement`；如果有 `offline` 也勾上（这样不用每小时重新登录） |

3. 保存后页面上会显示 **Client ID** 和 **Client Secret**，回到 Bridgepulse 的「⚙ 设置」里粘贴就行。
4. **这两个是你自己的密钥，只粘贴到 Bridgepulse 里，不要发给任何人（包括我）。**

## 遇到问题

- **打不开 / 一闪就没了**：确认第 1 步的 Node.js 装好了。Windows 在 PowerShell 里输入 `node -v`，Mac 在「终端」里输入 `node -v`，能看到 `v20` 这样的版本号就是装好了。
- **安装很慢或失败**：多半是网络问题。Windows 在 PowerShell 里先输入 `$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"`，Mac 在终端里先输入 `export ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"`，再输入 `npm install`。
- **点「连接 WHOOP」后浏览器报错**：多半是回调地址填错了，回到 developer.whoop.com 检查是不是 `http://localhost:3000/callback`。
- **提示「还没有数据」**：新设备至少要戴着睡一晚，WHOOP 才会算出第一份恢复度。
- **数字和 App 不一样**：左上角写着「示例数据」时是编出来的数字；你自己的数据刚同步可能慢一点，点右上角刷新。

## 请把这几件事告诉我

试完不管成没成功，都请告诉我：

1. **系统版本**：Windows 10 / 11，或 macOS 的版本（左上角苹果菜单 →「关于本机」能看到）。
2. **Mac 的芯片**：「关于本机」里写的是 **Apple M1 / M2 / M3…**（苹果芯片）还是 **Intel**。
3. **卡在哪一步**：上面第几步，看到了什么提示。
4. **截图**：小工具或终端窗口的截图。

**请不要发给我**：Client ID、Client Secret、`.env` 文件、`data` 文件夹，或者带有你真实健康数字的截图（截图前可以先打开「示例数据预览」再截）。
