# Bridgepulse 脉桥 试用步骤

谢谢你帮忙试用。Bridgepulse 把你的 WHOOP 数据翻成中文，放在电脑桌面上。它是非官方工具，只读取数据，所有东西只存在你自己的电脑上。不用装 Node.js，下载解压就能用。

先选你的电脑：[Windows](#windows) · [Mac（试用）](#mac试用)。

---

## Windows

1. **下载**：打开 [Bridgepulse-Windows.zip](https://github.com/HeathTeng/Bridgepulse/releases/latest/download/Bridgepulse-Windows.zip)（也可以在 [Releases 页面](https://github.com/HeathTeng/Bridgepulse/releases/latest) 里找到它）。
2. **解压**：在下载的 zip 上右键 →「全部解压缩」，放到一个好找的地方（例如桌面）。解压后是一个 **Bridgepulse** 文件夹。
3. **打开**：进入 Bridgepulse 文件夹，双击 **Bridgepulse.exe**（图标是一个绿圈里的 W）。
4. **如果出现「Windows 已保护你的电脑」**：点 **「更多信息」→「仍要运行」**。这是因为 Bridgepulse 没有买代码签名证书，第一次打开时 Windows 会提醒，以后不会再问。
5. **申请 WHOOP 开发者 ID**：按下面「申请 WHOOP 开发者 ID」一节做，拿到 Client ID 和 Client Secret。
6. **粘贴密钥**：第一次打开会直接出现设置框（以后点顶栏的「⚙ 设置」），把 Client ID 和 Client Secret 粘贴进去，点「保存」。
7. **连接 WHOOP**：点「连接 WHOOP」，在浏览器里登录 WHOOP 并同意授权，回到小工具就能看到你的数据。
8. **以后每次**：双击 Bridgepulse.exe 就行。想放到桌面上，可以在 Bridgepulse.exe 上右键 →「发送到 → 桌面快捷方式」。

## Mac（试用）

Mac 版还没在真机上完整测过，你可能是第一批用的人，遇到问题请按最后一节告诉我。

1. **看芯片**：左上角苹果菜单 →「关于本机」，写着 **Apple M1 / M2 / M3…** 的是苹果芯片，写着 **Intel** 的是 Intel。
2. **下载**：苹果芯片下载 [Bridgepulse-Mac-AppleChip.zip](https://github.com/HeathTeng/Bridgepulse/releases/latest/download/Bridgepulse-Mac-AppleChip.zip)，Intel 下载 [Bridgepulse-Mac-Intel.zip](https://github.com/HeathTeng/Bridgepulse/releases/latest/download/Bridgepulse-Mac-Intel.zip)。
3. **解压**：在「下载」里双击 zip，得到 **Bridgepulse.app**，把它拖进「应用程序」（或者任何好找的地方）。
4. **第一次打开**：在 Bridgepulse.app 上 **右键 →「打开」→ 再点「打开」**（直接双击会被系统拦下）。还是被拦的话，去「系统设置 → 隐私与安全性」，拉到下面点 **「仍要打开」**。
5. **申请 WHOOP 开发者 ID**：按下面「申请 WHOOP 开发者 ID」一节做，拿到 Client ID 和 Client Secret。
6. **粘贴密钥**：第一次打开会直接出现设置框（以后点顶栏的「⚙ 设置」），把 Client ID 和 Client Secret 粘贴进去，点「保存」。
7. **连接 WHOOP**：点「连接 WHOOP」，在浏览器里登录 WHOOP 并同意授权，回到小工具就能看到你的数据。
8. **以后每次**：双击 Bridgepulse.app 就行。隐藏成小图标的快捷键是 **Control+Option+W**。

## 申请 WHOOP 开发者 ID

每个人都要用自己的 WHOOP 账号申请一份，免费，大约 5 分钟。

1. 打开 [developer.whoop.com](https://developer.whoop.com)，点进开发者后台（Developer Dashboard），用你的 WHOOP 账号登录。第一次进去可能要先建一个团队（Team），名字随便填。
2. 点 **Create App**（新建应用），按下面填：

   | 格子 | 填什么 |
   |---|---|
   | App name（应用名） | 随便，例如 `My Bridgepulse` |
   | Contacts（联系邮箱） | 你自己的邮箱（只给 WHOOP 看，不会给 Bridgepulse） |
   | Privacy policy（隐私政策网址，如果要求填） | `https://github.com/HeathTeng/Bridgepulse` |
   | Redirect URL（回调地址） | `http://localhost:3000/callback`（一个字都不能错，不要加空格） |
   | Scopes（权限） | 勾选所有 **read** 开头的：`read:recovery`、`read:cycles`、`read:sleep`、`read:workout`、`read:profile`、`read:body_measurement`；如果有 `offline` 也勾上（这样不用每小时重新登录） |

3. 保存后页面上会显示 **Client ID** 和 **Client Secret**，回到 Bridgepulse 的「⚙ 设置」里粘贴就行。
4. **这两个是你自己的密钥，只粘贴到 Bridgepulse 里，不要发给任何人（包括我）。**

## 遇到问题

- **设置和数据存在哪里**：不在解压出来的文件夹里。Windows 在 `%APPDATA%\Bridgepulse`，Mac 在 `~/Library/Application Support/Bridgepulse`。换新版本时直接用新的压缩包替换旧的就行，设置和数据都还在。
- **点「连接 WHOOP」后浏览器报错**：多半是回调地址填错了，回到 developer.whoop.com 检查是不是 `http://localhost:3000/callback`。
- **打开后一直显示「连不上」**：可能是 3000 端口被别的程序占用了，关掉其他正在运行的 Bridgepulse（包括网页大看板）再打开。
- **提示「还没有数据」**：新设备至少要戴着睡一晚，WHOOP 才会算出第一份恢复度。
- **数字和 App 不一样**：你自己的数据刚同步可能慢一点，点右上角刷新。

## 请把这几件事告诉我

试完不管成没成功，都请告诉我：

1. **系统版本**：Windows 10 / 11，或 macOS 的版本（苹果菜单 →「关于本机」能看到）。
2. **Mac 的芯片**：苹果芯片还是 Intel，下载的是哪个 zip。
3. **卡在哪一步**：上面第几步，看到了什么提示。
4. **截图**：小工具或提示框的截图。

**请不要发给我**：Client ID、Client Secret、`.env` 文件、`data` 文件夹，或者带有你真实健康数字的截图。
