# WHOOP 指标中文说明

看 App 时对照用，以后也放进小工具的「词典」页和各指标的「这是什么」说明里。
以下说明按 WHOOP App 和官网的意思**用自己的话重写**，没有逐字翻译。这样以后放到 GitHub 上不会涉及搬运 WHOOP 的原文。

## 恢复 Recovery

**恢复度 Recovery（0–100%）**
身体今天准备好承受多少压力。主要由睡眠时的 HRV、静息心率、呼吸频率和睡眠表现算出来。
- 绿区 67–100%：可以安排高强度。
- 黄区 34–66%：保持中等强度。
- 红区 0–33%：优先休息和恢复。

**心率变异性 HRV（毫秒 ms）**
两次心跳之间的间隔有多大的变化，在睡眠中测量。它反映身体适应压力的能力。
- 每个人差别很大，年龄、性别、生活习惯、体能都会影响，只和自己的基线比，不要和别人比。
- 长期往上走，通常说明体能和整体状态在变好。
- 往下走，可能是练得太多、睡得不够、缺水或者压力大。

**静息心率 RHR（次/分 bpm）**
睡眠中最安静时段的心率。
- 越低通常说明心肺越有效率。
- 比自己平时高出一截，常见原因有：没恢复好、生病前兆、饮酒、睡前吃得晚、天热。

**呼吸频率（次/分 rpm）**
睡眠中每分钟呼吸的次数。
- 每个人非常稳定，一般只在小范围内波动。
- 突然明显升高，可能是身体在对抗感染或压力，值得留意。

**睡眠表现 Sleep Performance（%）**
昨晚睡够了身体需要的多少，同时考虑规律性、效率和睡眠压力。
- 最佳：85% 以上。
- 足够：70–85%。
- 差：70% 以下。

## 睡眠 Sleep

| 名称 | 意思 |
|---|---|
| 时长达成率 Hours vs. Needed | 实际睡眠时长 ÷ 今晚需要的睡眠时长 |
| 睡眠需求 Sleep Needed | 基础需求，加上近期负荷带来的额外需求，再加上要补的睡眠负债，减去白天小睡 |
| 睡眠负债 Sleep Debt | 前几晚没睡够、累积下来要补的部分 |
| 睡眠规律性 Sleep Consistency | 最近几天上床和起床时间有多一致，越规律越好 |
| 睡眠效率 Sleep Efficiency | 在床时间里真正睡着的比例 |
| 恢复性睡眠 Restorative Sleep | 深睡（SWS）和快速眼动睡眠（REM）的总和。深睡主要修复身体，REM 主要恢复大脑 |
| 醒来次数 Wake Events | 夜里短暂醒来的次数，多数自己察觉不到 |
| 睡眠压力 Sleep Stress | 睡眠中身体的压力水平。官方 API 拿不到，小工具里没有 |

## 负荷 Strain

**负荷 Strain（0–21）**
今天心血管系统承受了多少压力，包括运动和日常活动。数值越往上越难涨：从 18 涨到 19 比从 5 涨到 6 难得多。

**心率区间 HR Zones 1–5**
按最大心率的百分比划分：
- 区间 1：50–60%
- 区间 2：60–70%
- 区间 3：70–80%
- 区间 4：80–90%
- 区间 5：90–100%

区间 1–3 是有氧、耐力为主，适合打基础；区间 4–5 是高强度。按区间训练能帮你控制强度，提升心肺健康。
App 里的区间时间只统计**你记录下来的运动**，不是全天，小工具也一样。

**力量训练时长 Strength Activity Time**
做抗阻力训练（举重、器械、自重等）的时间。它不只是长肌肉，还有助于维持骨密度、心脏健康、灵活性和日常行动能力。
只有下面这些运动类型会被算进去：背婴儿/背幼儿、芭蕾把杆（Barre、Barre3）、Barry's、健美、抱石、拳击健身、霹雳舞、皮划艇（Canoeing、Kayaking）、F45、消防作业、功能性训练、HIIT、热瑜伽、柔术、风筝冲浪、体力劳动、普拉提（含器械普拉提）、力量举、攀岩、负重徒步、塑形瑜伽、铲雪、solidcore、力量训练、尾波滑水、举重、推轮椅、瑜伽。

## 健康监测 Health Monitor

把 HRV、静息心率、呼吸频率、血氧、皮温和你自己的正常范围比，全部在范围内就是「5/5 正常」。
**皮温**显示的是和你自己基线的差值，不是体温计读数。
